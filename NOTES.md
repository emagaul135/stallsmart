## App concept
- **StallSmart** — offline-first AI bookkeeper for market vendors. Paste a supplier message → on-device AI parses it into structured stock (JSON schema) → Firestore inventory → sales log → profit dashboard → Ask box. Short jobs on-device (Gemini Nano), long jobs cloud fallback. Every AI answer shows an ON-DEVICE / IN-CLOUD badge (`response.inferenceSource`). See PLAN.md for the full rationale.
- Stack: Vite + vanilla JS + `firebase` JS SDK v13 (`InferenceMode.PREFER_ON_DEVICE` / `PREFER_IN_CLOUD`, default cloud fallback `gemini-3.5-flash-lite`, structured output). Firestore offline persistence, anonymous Auth, App Check debug, Remote Config flag.
